
# Deep Learning-Based Face Segmentation & Recognition System using U-Net

## Project Overview
This project focuses on facial feature segmentation and face recognition using deep learning and the U-Net architecture.

## Technologies Used
- Python
- TensorFlow
- Keras
- OpenCV
- NumPy
- Matplotlib

## Dataset
CelebAMask-HQ Dataset

## Features
- Facial image preprocessing
- Facial feature segmentation using U-Net
- Face recognition and similarity analysis
- Testing with custom images

## Project Type
Final Year Major Project
